# Feed ordering and folder expansion behavior

```gherkin
Feature: 简体中文界面的订阅排序与文件夹展开偏好
  As a RSS 阅读器用户
  I want 调整订阅显示顺序并单独设置文件夹是否自动展开
  So that 侧边栏能符合我的阅读习惯

  Background:
    Given 用户已打开包含多个文件夹和订阅的侧边栏

  Scenario: 应用固定使用简体中文
    Given 用户的浏览器语言不是简体中文
    When 用户打开应用
    Then 页面文案、日期和系统提示应使用简体中文
    And 页面语言标记应为简体中文

  Scenario: 设置页不再提供语言切换
    Given 用户打开设置页的外观选项
    When 用户查看所有可配置项目
    Then 不应显示语言选择项
    And 其他外观偏好仍应正常配置

  Scenario: 兼容历史语言偏好
    Given 浏览器中保存了旧版本的语言偏好和其他界面偏好
    When 用户升级并打开新版本
    Then 旧语言偏好不应改变简体中文界面
    And 字体、分页、订阅顺序和文件夹展开偏好应继续恢复

  Scenario: 按规则排列订阅
    Given 同一文件夹内存在多个名称、未读数和添加时间不同的订阅
    When 用户选择按名称、未读数或最近添加排序
    Then 每个文件夹内的订阅应立即按所选规则排列
    And 用户原先保存的手工顺序不应被覆盖

  Scenario: 手工调整订阅位置
    Given 用户选择了手工排序
    When 用户点击某个订阅的上移或下移操作
    Then 该订阅应与同一文件夹内相邻的订阅交换位置
    And 刷新页面后仍应保持调整后的顺序

  Scenario: 手工排序的边界
    Given 用户选择了手工排序
    When 订阅已位于所属文件夹的最顶部或最底部
    Then 对应方向的移动操作应不可用
    And 订阅不应跨文件夹移动

  Scenario: 新订阅加入已有手工顺序
    Given 用户已保存一套手工顺序
    When 系统出现尚未包含在该顺序中的新订阅
    Then 新订阅应显示在现有手工顺序之后
    And 已保存订阅之间的相对位置应保持不变

  Scenario: 文件夹默认自动展开
    Given 文件夹没有明确关闭自动展开
    When 用户打开或刷新侧边栏
    Then 该文件夹应自动展开

  Scenario: 文件夹改为仅手工展开
    Given 某个文件夹当前启用了自动展开
    When 用户关闭该文件夹的自动展开选项
    Then 该文件夹应立即收起
    And 刷新页面后仍应保持收起
    And 用户仍可通过展开按钮手工打开该文件夹

  Scenario: 文件夹偏好互不影响
    Given 侧边栏存在多个文件夹
    When 用户只修改其中一个文件夹的自动展开选项
    Then 其他文件夹的展开策略应保持不变

  Scenario: 无效的历史偏好数据
    Given 浏览器中存在无法识别的排序或展开偏好
    When 应用恢复用户偏好
    Then 应回退到安全的默认排序与展开行为
    And 侧边栏应继续正常显示
```
